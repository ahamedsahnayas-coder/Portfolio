# 🌐 Portfolio — Nayas AHAMEDSAH

Portfolio personnel développé en HTML5 et CSS3 pure.  
Conçu pour présenter mon profil, mes compétences et mes projets universitaires dans le cadre de ma recherche d'alternance.

Site statique — directement consultable via GitHub.

---

## 📁 Structure du projet

```
portfolio/
├── index.html          # Structure et contenu de la page
├── styles.css          # Mise en forme et animations
├── images/             # Photos de profil et visuels des projets
└── documents/
    └── CV_Nayas.pdf    # CV téléchargeable
```

---

## 📌 Sections

- **Accueil** — Présentation rapide et statut de recherche d'alternance
- **À propos** — Profil, objectifs à court et long terme
- **Compétences** — Savoir-faire techniques (web, programmation, bases de données, réseaux) et savoir-être
- **Projets** — 4 projets universitaires réalisés en groupe (SAÉ BUT1)
- **Parcours** — Timeline de formation et expériences
- **Contact** — Accès au CV, GitHub, LinkedIn et formulaire mail

---

## 🛠️ Technologies utilisées

| Technologie | Usage |
| HTML5 | Structure sémantique |
| CSS3 | Design, animations, responsive |
| Google Fonts | DM Sans + DM Mono |
| Font Awesome 6 | Icônes |

---

## ✨ Points notables

- Design sombre (dark theme) avec palette bleue/teal/violet
- Mise en page responsive (mobile, tablette, desktop) via CSS Grid et media queries
- Navigation fixe avec effet de soulignement au survol
- Badges de compétences, timeline de parcours et cartes de projets animées au hover
- Liens directs vers CV PDF, GitHub et LinkedIn
